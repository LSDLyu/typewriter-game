# 纸上电报局 · Typewriter Game

以 1950 年代便携式机械打字机为灵感的家庭英语打字游戏。五关依次练习字母、空格、句子与双色色带；每行准确打完后，拉动回车杆继续。桌面键盘和手机屏幕键帽都可操作。

- 中文正式路径：<https://edu.alading.org/games/typewriter>
- English: <https://edu.alading.org/en/games/typewriter>
- 独立试玩：<https://lsdlyu.github.io/typewriter-game/>（加 `?lang=en` 可预览英文）
- 纯前端，无后端、追踪脚本或外部字体请求。通关和设置仅存于当前浏览器。

## 玩法

按任务栏给出的文字依次敲键。打错或用错色带时，该字会标记出来；按退格键修正。一行完全正确后，用实体键盘 `Enter`、屏幕按钮或机器左侧回车杆换行。通关后根据失误和修正次数获得分数与星级，并解锁下一关。

11 个单词与短句均有对应插画：猫、太阳、挥手问候、晴天散步、打字、朋友鼓励、红玫瑰、蓝天、生日许愿、读书和故事结束。图片与文字、朗读按钮位于打字区上方；手机和平板滚动到键盘时仍可看到当前提示。换行、换关、重玩会同步切换图片，加载失败时文字与打字功能继续可用。

音效、震动和完成动画可以分别关闭。不支持震动的设备会禁用震动开关；系统要求减少动态效果时会停用动画。按键与回车保留 Web Audio 机械音；CAT、SUN、HELLO 使用 Wikimedia Commons 真人录音；完整英文句子及英文提示保留 Iris Bot MP3。中英文界面统一使用简短英文录音提示；总开关在页首，音乐、音效和语音分项在页尾。

## 本地运行

在仓库目录执行 `python3 -m http.server 4173 --directory public`，访问 <http://localhost:4173/>。测试使用 `node --test tests/*.test.mjs`。

## 部署

线上中英文游戏目录由现有 `lisa-games-router` Worker 生成。`integration/router-extension.js` 是追加到该 Worker 当前源码末尾的接入代码：为两个目录增加第三张卡片，并把两个语言路径及其静态资源转发到本仓库的 GitHub Pages。它也直接提供 `/en/games`，避免站点的尾部斜杠规范化造成重定向循环。修改目录时须保留数学路径怪探和 Lisa 的现有路由并验证四个语言入口。

`worker.mjs` 和 `wrangler.jsonc` 提供独立 Cloudflare 静态资源部署方案，只匹配打字机游戏的中英文路径，绝不接管游戏目录。若使用独立 Worker，还需在目录 Worker 中加入卡片入口。

GitHub Pages 工作流只发布 `public/` 下的静态文件。正式站点当前通过已有的目录 Worker 转发此预览地址。

## Iris Bot 音频（2026-10-10）

接入用户提供的原始 MP3：中英文玩法/反馈语音和情境音效。页面载入不自动朗读；通过游戏操作或朗读按钮启动。声音设置可保存，关闭声音和切到后台会停止录音；快速重试不会堆叠语音。素材清单与原始脚本随资源保存。

## 单词真人录音

CAT、SUN、HELLO 已接入美式真人录音，任务区提供中英文来源页及逐项作者、许可。另 8 段完整短句保留连贯的 Iris 录音。来源页由 `node scripts/build-word-credits.mjs` 根据实际署名数据生成。见 [录音检查记录](docs/WORD_AUDIO_REVIEW.md)。main 更新会自动发布正式站点使用的 GitHub Pages。


## 本轮界面与中文提示

页首、页尾使用教育站维护的统一游戏导航，向下滚动时缩为窄条。`public/game-shell.js` 与教育站、数学路径和奇妙大楼中的对应文件保持一致。

中文提示不再调用原 Miriam 多语种合成录音。`MandarinPrompts` 只选择普通话音色，使用短句和正常语速；普通话提示可独立开关，英文单词真人录音不受影响。关闭游戏声音、重听英文、切换关卡或进入后台会取消待播放提示。音色因设备而异，缺少普通话音色时只显示原有文字反馈，不能把自动测试视为真人试听认可。

## 单词与短句配图

`public/target-pictures.mjs` 维护每个任务的画面位置与中英文替代文字。`public/illustrations/word-scenes.png` 是为本游戏生成的完整插画图集（1448 × 1086，4 列 × 3 行，单格 362 × 362）；网页通过 CSS 显示对应格，原图不裁切。前 11 格对应任务，最后一格信封暂未使用。整局仅请求一次图集，按键输入不重新加载图片。图集不来自 Wikimedia Commons；录音仍沿用各自来源与许可，参见页面的“单词录音来源”。

## 按实物参考图调整的键盘

根据用户提供的机械打字机照片，键盘采用灰绿色圆角盾形键帽、奶油色字符、可见金属键杆、四排错列与深色长空格键；保留 QWERTY。新增照片中的数字、符号和分数字样，按键都能操作。输入不符合当前词句的数字/符号会像错字一样标记，可用退格修正；五关词句与配图、录音保持原样。

⇧ 点击一次后使用键帽上方的符号，打印后恢复；实体 Shift 键也支持显示换档状态。屏幕 TAB 输入一个空格，实体 Tab 继续用于焦点导航。键盘上的退格与回车和原有按钮/回车杆作用一致。

“放大键帽”在当前浏览器记住选择；放大时每枚按键的触摸范围至少 44 × 44 CSS px，窄屏可在键盘内部横向滑动，排列不变；长空格键保持在可见区域。切回“显示完整键盘”可查看整台键盘。放大是对小屏触摸的辅助；照片并非完全按比例复制。

新增控件可用键盘操作，按下动画遵循减少动态效果偏好。共享声音设置和真人录音来源沿用现有实现。CSS 与更新的入口模块带版本查询，避免旧缓存把新版键盘结构与旧样式混用。

验证：`npm test`；浏览器验收用 `python3 -m http.server 4173 --directory public` 配合 `python tests/keyboard.browser.py`。正式站点继续使用现有目录转发到 GitHub Pages，发布本仓库即可更新。
